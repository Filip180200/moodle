# Materialy podstawowe

Katalog zawiera interaktywne wprowadzenia do podstawowych pojec metodologicznych i statystycznych, przydatne przed zajeciami z metod badan i statystyki.

## Cwiczenia

| Plik | Zakres cwiczenia |
| --- | --- |
| [`1.html`](1.html) | Jak dziala nauka? Uczestnik porownuje wiedze potoczna, popularnonaukowa i naukowa, poznaje piramide wiarygodnosci wiedzy oraz rozwiazuje quiz rozpoznawania rodzaju wiedzy. |
| [`hipotezy.html`](hipotezy.html) | Jak budowac hipoteze. Kreator prowadzi krok po kroku przez skladniki hipotezy o zwiazku miedzy zmiennymi (zmienna, kierunek, zmienna wynikowa, grupa) i pokazuje przyklady zlych i dobrych hipotez. |
| [`korelacje.html`](korelacje.html) | Ekspert statystyczny - korelacja. Uczestnik manipuluje sila i kierunkiem zwiazku miedzy dwiema zmiennymi (np. ekstrawersja i neurotyzm) i obserwuje na biezaco wspolczynnik r, istotnosc i wykres rozrzutu. |
| [`monety.html`](monety.html) | Symulacja rzutu moneta. Cwiczenie pozwala wykonac pojedynczy rzut lub wiele eksperymentow i zobaczyc, jak rozklad liczby orlow zbliza sie do rozkladu normalnego wraz ze wzrostem liczby prob. |

## Zasoby

Strony sa samodzielne i nie wymagaja plikow pomocniczych. `korelacje.html` korzysta z bibliotek ladowanych z sieci (Tailwind CSS, Google Fonts) - przy testowaniu potrzebne jest polaczenie z internetem.

## Dodawanie materialow

Nowe strony zapisuj bezposrednio w tym katalogu, uzywajac opisowej nazwy pliku. Jesli strona wymaga plikow pomocniczych, przechowuj je w podkatalogu o tej samej nazwie co strona.
