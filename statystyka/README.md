# Narzedzia statystyczne

Katalog grupuje interaktywne narzedzia wspierajace dobor analizy i interpretacje wynikow.

## Cwiczenia

| Plik | Zakres cwiczenia |
| --- | --- |
| [`wybor_testu.html`](wybor_testu.html) | Interaktywny przewodnik po wyborze testu. Uczestnik okresla typ pytania, liczbe i zaleznosc grup oraz normalnosc rozkladu, a strona rekomenduje test i tworzy hipotezy H0 i H1. Obejmuje miedzy innymi testy t, ANOVA, ANOVA z powtarzanym pomiarem, U Manna-Whitneya, Wilcoxona, Friedmana, korelacje, chi-kwadrat, MANOVA i regresje liniowa. |
| [`korelacje.html`](korelacje.html) | Cwiczenie z interpretacji korelacji. Uczestnik odczytuje kierunek, sile i istotnosc statystyczna zwiazku na podstawie prezentowanych wartosci. |

Strony korzystaja z bibliotek ladowanych z sieci. Przy testowaniu potrzebne jest polaczenie z internetem.
